# 電子書籍はPCで読むのが個人的に一番良い

最近は、技術書とかは電子書籍で買うようにしている。買ってすぐに読める（紙だと店舗に在庫がなくて取り寄せが必要な時もある）、持ち運びが楽（特に技術書は厚くて重い）だからである。

で、その電子書籍を読むにはPC（具体的にはlaptop）がいいことに気づいた。

理由は以下の通り。

- 手が楽。タブレットとかスマホで見るとずっと手で持っておかないといけないが、PCであれば机に置くだけで良い
- 知らないことがあればすぐ調べられる。これに関してはタブレット、スマホでも同じじゃんと思うかもしれないが、入力の便利さはキーボード>>>>>>>>>>>>フリック入力なのである。

しかし、以下のようなデメリットもあるので、気をつけなけらばならない。

- PCは色々なことができるので、気が散るということである。ちょっと知らない単語があるので調べようとして、サイトを見る、サイト内の広告が気になって、リンク先を見る、気づいたら関係ないことを１０分くらいみている。ということになりかねない。
