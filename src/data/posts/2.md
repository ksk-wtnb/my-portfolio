# コードハイライトを導入してみた

やったことはタイトルの通りである。
上手くいっていれば、以下のコードがいい感じに表示されているはず。

```js
console.log('hello')
```

これもAI(Claude Code)に教えてもらいながら実装した。
ただ、何も知らないことをAIに質問攻めしながら、進めると本筋から脱線するので、よくわからない（迷子になってきたりする）。
なので、どこかのタイミングで本を使ったり体系的に学ぶ必要があるのだろうなと思った。
ただ、仕事でコードを書いているわけではないので、多少効率の悪いやり方でもいいかなと思おっているのでリラックスして取り組めている。
また、職場の方で、勉強されている方は一度に全部理解しなくてもいいかなという気持ちで取り組んでいるらしい。確かに、全部理解しながらやっていくと終わらないこともあるし、疲れて進まないし、それくらいの心持ちでいいのかもしれない。
